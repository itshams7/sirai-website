# SIRAI website

**SIRAI** | Sudan Initiative for Resilience & Inclusive Action

**Built with communities.**

Official website for SIRAI, an independent community initiative in development, focused on resilience, shared knowledge, and locally led action in Sudan.

## Website files

- `index.html`: bilingual English and Arabic homepage, including the founder profile and photo.
- `water-toolkit.html`: WaterShare v0.1, a community water-planning educational tool.
- `assets/styles.css`: responsive website design.
- `assets/app.js`: translations, Arabic RTL switching, and interactive toolkit.
- `assets/founder-shams.png`: founder portrait.
- `assets/favicon.svg`: project icon.

## Publishing

Upload the **contents** of the website folder to this repository's root, so `index.html` is beside this README. Then go to **Settings > Pages > Build and deployment > Deploy from a branch**, select **main** and **/(root)**, and save.

The site will appear at https://itshams7.github.io/sirai-website/ once GitHub Pages is enabled and deployment finishes.

## Accuracy

SIRAI is not currently a registered NGO, and its site labels projects under development. Prior community work by the founder is presented separately from SIRAI activities. WaterShare is an educational planning resource, not a substitute for local public-health or engineering guidance.
